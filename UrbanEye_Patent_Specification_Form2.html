FIELD OF THE INVENTION

The present invention relates generally to intelligent transportation systems (ITS), distributed edge computing, and automated computer vision infrastructure maintenance. More particularly, the present invention relates to an edge-to-cloud cyber-physical system that concurrently executes high-throughput neural pavement defect extraction and throttled automatic number plate recognition (ANPR), while cryptographically gating cloud telemetry transmission to protect citizen privacy and optimize municipal budget allocation.

BACKGROUND OF THE INVENTION AND PRIOR ART DEFICIENCIES

Municipal road inspection has traditionally depended on manual visual audits, dedicated profiling vans equipped with expensive laser crack measurement systems (LCMS costing over $100,000 per unit), or uncalibrated smartphone crowdsourcing. Existing approaches suffer from severe technical drawbacks:

  1. Edge Thermal Bottlenecks: Running multiple deep neural models simultaneously (e.g. YOLO pavement segmentation and OCR for license plates) on mobile edge devices results in severe thermal throttling, frame rate drops, and hardware shutdown.
  2. Unbounded Telemetry and Surveillance Risks: Edge devices mounted on municipal transit fleets typically record continuous video feeds without authentication, raising severe citizen surveillance and data leakage concerns in public transit corridors.
  3. Fleet Spatial Ingestion Redundancy: Hundreds of transit buses traversing identical corridors record the same road hazard repeatedly, leading to database degradation and distorted municipal work-order queues.

OBJECTS OF THE PRESENT INVENTION

The primary object of the present invention is to provide a unified, ultra-low-cost, high-precision edge-AI transit sensor and command system that solves edge thermal limits, guarantees privacy-compliant telemetry gating, and models municipal infrastructure degradation in real-time.

SUMMARY AND KEY TECHNICAL NOVELTIES

The invention introduces four core patentable technical architectures:

  1. Load-Adaptive Dual-Cadence Edge Inference Engine: A decoupled multi-thread architecture that decouples primary road defect inference (8–12 FPS) from secondary ANPR OCR inference. Latency on the primary thread dynamically throttles the OCR polling cadence from 180 ms to 400 ms during sustained processing loads, maintaining 100% video fluidness.
  2. Zero-Telemetry Ephemeral Cipher-Gated Ingestion Handshake: A physical pairing protocol where camera hardware executes purely local viewfinder preview without capturing, inferring, or transmitting telemetry until verified by an authoritative district administrator via an out-of-band 6-digit ephemeral PIN.
  3. Multi-Angle Rotation OCR with HSRP Normalization: Context-aware character confusion correction matrix (resolving O/0, I/1, B/8, S/5, Z/2) combined with multi-orientation projective normalization (0°, 90°, 270°) and automatic HSRP "IND" prefix stripping.
  4. Spatio-Temporal Cluster Deduplication and Schedule of Rates (SoR) Costing: Micro-geofenced clustering (15–25m decay envelope) that eliminates multi-bus duplicate hazard logging, paired with a perspective ground-scale equation that computes physical diameter and converts defect geometry into municipal repair cost estimates (calibrated to Indian PWD/NHAI standards).

DETAILED TECHNICAL DESCRIPTION

The edge device incorporates an on-device ONNX Runtime inference engine executing a multi-class YOLOv8 neural network. The operational sequence is as follows:

1. Hardware Camera Feed Initialization → Local Surface Provider (No capture). 2. Ephemeral PIN Request → Command Center Handshake (/api/bus-sessions/request-pin). 3. State Verification Polling → Awaiting District Head Authorization. 4. Paired State Transition → Unlock Edge Inference & GPS Telemetry Ingestion. 5. Primary Defect Thread [Fast Cadence: ~90ms] ↔ Secondary ANPR Thread [Adaptive: 180-400ms]. 6. Multi-Frame Temporal Tracker IoU Matching → Persistence Confirmation. 7. Geo-Tagged Event Dispatch → Server-Side Micro-Geofence Deduplication. 8. Road Quality Index (RQI) & Traffic Heatmap Aggregation on Polyline Topologies.

ABSTRACT

A load-adaptive dual-cadence edge-computing system and method for automated municipal infrastructure surveillance. The system operates on edge mobile sensors mounted on public transit fleets to concurrently extract pavement surface hazards and vehicle identifiers. A primary neural inference thread executes real-time road defect detection, while a secondary background thread executes throttled ANPR text recognition with dynamic load-adaptive polling. Capture and cloud ingestion are strictly hardware-gated until unlocked via an out-of-band ephemeral key pairing protocol with a central command center. Server-side spatio-temporal micro-geofencing deduplicates multi-fleet hazard logs and computes automated municipal repair cost forecasts.
